# 오갱끼데스까 — 월드메모리 주차·셔틀

공사 기간 한시 운영하는 주차·셔틀 관리 웹앱입니다. 직원은 로그인 없이 주소만 열어서 씁니다.

- 본사 주차 → 이평석 부장 만차 사인 → 신평동 녹색주차장 / 개별 주차
- 출근 셔틀 08:20: 08:20까지 녹색주차장 주차자가 있을 때만 운행
- 퇴근 셔틀(시각은 관리 칸에서 설정): 녹색주차장에 차량이 남아 있을 때만 운행
- 개별 주차한 직원이 근처 빈자리를 알리는 "외부주차 자리 알림" 코너
- 주차 기록은 30일 지나면 자동 삭제, 직원 명단과 설정은 보존

## 실행 (Windows PC/서버)

`run.bat` 더블클릭 → 처음 한 번은 설치까지 진행됩니다.
직원은 `http://<서버 PC의 IP>:8010` 으로 접속합니다. Windows 방화벽에서 8010 포트 인바운드를 허용해야 다른 PC에서 열립니다.

## 실행 (Docker)

```
docker compose up -d --build
```

## 데이터

- `data/parking.db` (SQLite) 한 파일에 직원 명단·설정·주차 기록이 모두 들어 있습니다. 백업은 이 파일만 복사하면 됩니다.
- 보관 기간은 환경변수 `KEEP_DAYS`로 바꿉니다 (기본 30).
