시스템 개요 및 역할 구분
WWM 매입검수 플랫폼의 구조와 3가지 역할을 확인하세요

WWM 매입검수 플랫폼은 매입된 IT 기기의 검수 데이터를 체계적으로 관리하고, QR 라벨 출력 및 엑셀 보고서 생성을 지원하는 사내 전용 시스템입니다.

전체 프로세스는 관리자의 매입건 등록 → 검수자의 1차 검수 → 최종검수자의 판정 스탬핑 순서로 진행됩니다.

관리자 (ADMIN)
  • 매입건 등록 / 삭제
  • QR 코드 행 추가 / 삭제
  • 검수 완료 처리
  • 엑셀 다운로드 (전체)
  • 매입건 목록 전체 조회
  • 스탬핑 직접 편집 불가
검수자 (INSPECTOR)
  • 매입건 목록 조회
  • 1차 검수 입력 / 수정
  • QR 라벨 출력
  • 스탬핑 불가
  • 매입건 등록 불가
  • 엑셀 다운로드 불가
최종검수자 (FINAL)
  • 매입건 목록 조회
  • 스탬핑 (판정·등급·매입가)
  • 인라인 스탬핑 (목록에서)
  • QR 라벨 출력
  • 엑셀 다운로드 (완료 건)
  • 1차 검수 입력 불가

로그인
모든 역할 공통 — inspect01.onrender.com/login
로그인 화면
브라우저에서 inspect01.onrender.com 또는 inspect01.onrender.com/login 에 접속합니다. 왼쪽 패널에 브랜드 소개가 표시되고, 오른쪽 패널에 로그인 폼이 나타납니다.
inspect01.onrender.com/login
  1. 아이디 입력란에 계정 아이디를 입력합니다.
  2. 비밀번호 입력란에 비밀번호를 입력합니다.
  3. 로그인 버튼을 클릭합니다.
  4. 로그인 성공 시 매입건 목록 화면으로 이동합니다.
⚠ 주의: 아이디 또는 비밀번호가 틀리면 "아이디 또는 비밀번호가 올바르지 않습니다." 메시지가 표시됩니다. 계정 발급 문의는 시스템 관리자에게 연락하세요.
💡 역할 확인: 로그인 후 화면 우측 상단 내비게이션 바에서 자신의 이름과 역할 배지(ADMIN / INSPECTOR / FINAL)를 확인할 수 있습니다.

STEP 3-1
매입건 목록 확인
로그인 후 첫 화면입니다. 등록된 모든 매입건이 카드 형태로 표시됩니다. 각 카드에는 업체명, 수량, 입고일, 담당자, 검수 진행률(완료/전체)이 표시됩니다. 상태 배지는 진행중과 완료 두 가지입니다.
inspect01.onrender.com — 홈 화면
💡 신규 등록 버튼: ADMIN 계정에서만 우측 상단에 "+ 신규 매입건 등록" 파란 버튼이 표시됩니다. INSPECTOR / FINAL 계정에서는 이 버튼이 보이지 않습니다.

매입건 상세 관리
목록에서 매입건 카드를 클릭하면 상세 화면으로 이동합니다. 상단에는 업체 기본정보, 하단에는 QR 코드별 검수 리스트가 테이블로 표시됩니다.
inspect01.onrender.com/orders/{id}

검수 완료 처리
모든 QR 슬롯의 1차 검수가 완료되면 하단 우측에 "✓ 검수 완료 처리" 초록 버튼이 활성화됩니다. 이 버튼을 클릭하면 해당 매입건의 상태가 진행중 → 완료로 변경됩니다.
모든 검수 완료 후 하단 버튼 영역
💡 버튼 비활성화: 미검수 항목이 남아있으면 버튼이 회색으로 표시되며 클릭할 수 없습니다. 버튼 위에 "검수 미완료 (N건 남음)" 텍스트가 표시됩니다.
STEP 3-5
엑셀 다운로드

검수자 (INSPECTOR) 업무 흐름
1차 검수 데이터 입력 및 QR 라벨 출력
STEP 4-1
매입건 목록 확인
로그인 후 동일하게 매입건 목록이 표시됩니다. 검수자 계정에서는 "+ 신규 매입건 등록" 버튼이 표시되지 않습니다. 자신이 검수해야 할 매입건 카드를 클릭하여 상세 화면으로 이동합니다.
INSPECTOR 로그인 후 홈 화면 — 우측 상단 "INSPECTOR" 배지 확인
STEP 4-2
1차 검수 입력
매입건 상세 화면에서 검수가 필요한 행의 "검수입력" 파란 버튼을 클릭합니다. 이미 검수된 행은 "수정" 회색 버튼으로 표시됩니다.
파란 "검수입력" 버튼이 있는 미검수 행 확인
inspect01.onrender.com/orders/{id}/inspect/{qrId}

검수자자동 입력현재 로그인한 계정 이름으로 자동 설정
  1. 모든 항목을 입력한 후 "1차 저장" 파란 버튼을 클릭합니다.
  2. 저장 성공 시 매입건 상세 화면으로 돌아가며, 해당 행이 "수정" 버튼으로 바뀝니다.
  3. 검수 진행률(N/전체) 숫자가 1 증가하는 것을 확인합니다.
⚠ 다른 검수자가 완료한 항목: 다른 검수자가 이미 입력한 항목은 읽기 전용으로 표시됩니다. 자신이 직접 입력한 항목만 수정할 수 있습니다.
💡 판정·등급·매입가: 1차 검수 화면 우측 하단에 "판정·등급·매입가는 최종검수자가 Stamping 단계에서 입력합니다" 안내가 표시됩니다. 이 항목들은 검수자가 직접 입력하지 않습니다.
STEP 4-3
QR 라벨 출력
검수가 완료된 행의 "라벨" 초록 버튼을 클릭합니다. 라벨 화면에서는 QR 코드 이미지와 검수 스펙이 라벨 형식으로 표시됩니다. 브라우저의 인쇄(Ctrl+P) 기능을 사용하여 출력합니다.
inspect01.onrender.com/orders/{id}/inspect/{qrId}/label
💡 라벨 내용: 업체명, 입고일, QR 코드, 순번, 제조사, 모델명, CPU, RAM, 저장장치, VGA, 화면 크기, 해상도, 액정 상태, 키보드/터치, 배터리 손실률, 아답터, 바라시 여부, 특이사항, 검수자 이름이 포함됩니다.
5
최종검수자 (FINAL_INSPECTOR) 업무 흐름
스탬핑(판정·등급·매입가 결정) 및 엑셀 출력
STEP 5-1
매입건 목록 및 스탬핑 현황 확인
로그인 후 동일한 매입건 목록이 표시됩니다. 상세 화면에 진입하면 검수 리스트 헤더에 검수 진행률과 스탬핑 현황(스탬핑 N/검수완료 N)이 함께 표시됩니다.
헤더 영역의 "스탬핑 N/N" 보라색 텍스트 확인
💡 스탬핑 완료 행 표시: 스탬핑이 완료된 행은 보라색 배경으로 표시되며, 동작 열에 스탬핑완료 배지가 나타납니다.
STEP 5-2
인라인 스탬핑 (목록 화면에서 직접 입력)
최종검수자는 매입건 상세 화면의 테이블에서 직접 판정·등급·매입가를 입력하고 저장할 수 있습니다. 별도 페이지로 이동하지 않아도 됩니다.
FINAL 계정 — 1차 검수 완료된 행에 판정/등급/매입가 입력 폼 표시
  1. 1차 검수가 완료된 행(배경색 없음)에서 판정 드롭다운을 클릭합니다.
  2. 판정을 선택합니다: 모델(정상 모델) / 불량 / 부품(부품용)
  3. 등급 드롭다운에서 등급을 선택합니다: S / A / B / C
  4. 매입가 숫자 입력란에 금액을 입력합니다.
  5. 해당 행 맨 우측 "저장" 보라색 버튼을 클릭합니다.
  6. 저장 성공 시 해당 행 배경이 보라색으로 바뀌고 스탬핑완료 배지가 표시됩니다.
항목선택지의미
판정 모델 정상 동작하는 제품 (양품으로 모델 분류)
불량 사용 불가 또는 주요 결함이 있는 제품
부품 부품 수거 목적의 제품
등급 S / A / B / C S: 최상급 → C: 하급 (내부 기준에 따라 부여)
매입가 숫자 입력 해당 기기의 최종 매입 금액 (원 단위)
⚠ 1차 검수 미완료 행: 1차 검수가 완료되지 않은 행에는 스탬핑 입력 폼이 표시되지 않습니다. 반드시 검수자가 먼저 1차 검수를 완료해야 합니다.
💡 재스탬핑: 이미 스탬핑된 항목도 다시 값을 변경하고 "저장" 버튼을 누르면 재스탬핑됩니다. 저장 시 스탬퍼 이름과 시각이 갱신됩니다.
STEP 5-3
검수 완료 건 엑셀 다운로드
최종검수자는 상태가 "완료"인 매입건에 한해 엑셀 다운로드가 가능합니다. 완료 상태의 매입건 상세 화면 하단 좌측에 "📊 엑셀 다운로드" 버튼이 표시됩니다. 진행중 상태의 매입건에서는 버튼이 나타나지 않습니다.
진행여부: "완료" 배지 + 하단 "📊 엑셀 다운로드" 버튼
⚠ 진행중 건 다운로드 불가: 최종검수자 계정에서 아직 완료 처리되지 않은 매입건은 엑셀 다운로드 버튼이 표시되지 않습니다. 완료 처리는 관리자(ADMIN)만 가능합니다.

자주 묻는 질문 (FAQ)
운영 중 자주 발생하는 상황별 해결 방법
Q. 스탬핑 저장 버튼을 눌렀을 때 "스탬핑은 최종검수자 계정만 가능합니다" 메시지가 뜹니다.
A. 현재 로그인 계정이 FINAL_INSPECTOR 역할이 아닙니다. 화면 우측 상단 배지를 확인하세요. FINAL 계정으로 다시 로그인해야 스탬핑할 수 있습니다.
Q. "검수 완료 처리" 버튼이 회색으로 비활성화되어 있습니다.
A. 1차 검수가 완료되지 않은 항목이 남아있습니다. 버튼 텍스트에 "(N건 남음)"이 표시됩니다. 검수 리스트에서 배경이 노란색인 행을 찾아 검수를 먼저 완료하세요.
Q. 다른 검수자가 입력한 항목을 수정하고 싶습니다.
A. 보안상 자신이 입력한 항목만 수정할 수 있습니다. 다른 검수자가 입력한 항목은 읽기 전용으로 표시됩니다. 수정이 필요할 경우 관리자에게 문의하거나, 특이사항란에 수정 내용을 기재하는 방법을 사용하세요.
Q. 최종검수자인데 엑셀 다운로드 버튼이 보이지 않습니다.
A. 최종검수자는 완료 처리된 매입건에서만 엑셀 다운로드가 가능합니다. 해당 매입건 상단의 상태 배지가 ✓ 완료인지 확인하세요. 아직 ● 진행중이라면 관리자에게 완료 처리를 요청하세요.
Q. QR 슬롯 수를 잘못 등록했습니다. 수정할 수 있나요?
A. 관리자(ADMIN) 계정에서 행 추가 또는 행 삭제로 조정할 수 있습니다. 단, 행 삭제는 1차 검수가 완료되지 않은 행만 가능합니다. 이미 검수 데이터가 입력된 행은 삭제할 수 없습니다.
Q. 로그인이 되지 않습니다.
A. 다음 사항을 확인하세요:
① 아이디와 비밀번호가 정확한지 확인 (대/소문자 구분)
② 계정이 비활성화되었을 수 있으므로 시스템 관리자에게 문의
③ 인터넷 연결 상태 확인 (inspect01.onrender.com 서버가 응답하는지 확인)
