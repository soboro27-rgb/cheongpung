# 01. 업무 플로우

## 전체 개요

```
[1] 매각 요청 입력  →  [2] 자산 정규화  →  [3] 이력 데이터 조회
                                                    ↓
[6] 최종 견적서  ←  [5] 견적 산출 엔진  ←  [4] 시세·시장 반영
```

## 6단계 메인 플로우

### 1. 매각 요청 입력 (Bid Request Input)
영업담당자가 고객사로부터 받은 매각 자산 리스트를 시스템에 입력하는 단계.

**입력 방법**:
- 엑셀(XLSX) / CSV 파일 업로드 (1차 우선순위)
- 수기 입력 (소량 자산)
- 사진 + OCR (Phase 2 이후)
- 기관 발주서 PDF 파싱 (Phase 3 이후)

**입력 데이터**:
- 고객사 정보 (`Customer`)
- 입찰 방식 (공개입찰/지명입찰/수의계약)
- 반입 예정일, 반입 지역
- 데이터 삭제 방식 (물리 파쇄/소프트웨어 와이핑/없음)
- 자산 리스트 (모델명, 연식, 등급, 수량)

### 2. 자산 정규화 (Asset Normalization)
입력된 자산 정보를 표준화된 `AssetMaster`와 매칭.

**처리 내용**:
- 모델명 표준화: "LG그램 14인치", "LG gram 14" → `LG-GRAM-14Z90P`
- 매칭 알고리즘: Levenshtein 거리 + 키워드 추출
- 상태 등급 자동 분류: A(미사용/최상), B(정상사용), C(고장·결함)
- 매칭 결과 표시: 완전매칭 / 유사매칭 / 미매칭

**예외 처리**:
- 미매칭 자산은 영업담당자에게 추가 정보 요청
- 신규 모델인 경우 `AssetMaster`에 등록 후 진행

### 3. 이력 데이터 조회 (History Lookup)
정규화된 자산 마스터를 기준으로 과거 거래·낙찰 이력 검색.

**조회 대상**:
- `SalesHistory`: 실제 매각 거래가 (가장 중요)
- `BidHistory`: 입찰 참여 이력 (낙찰/패찰)
- 기간 필터: 최근 6/12/24개월
- 기관 필터: 동일 기관 / 동일 분야 / 전체

**가중치**:
- 최신 거래일수록 높은 가중치 (시간 감쇠 함수)
- 동일 기관의 이력은 1.5배 가중치
- 이력 개수가 적으면 신뢰도 감소

### 4. 시세·시장 반영 (Market Adjustment)
외부 시세 데이터를 참조하여 현재 시점의 시장 가격으로 보정.

**데이터 소스**:
- 다나와 중고시세 (국내)
- eBay / 해외 중고시장
- 환율 (USD/KRW)
- 신품 가격 추이 (감가 보정)

**보정 방식**:
- 시세 트렌드 분석 (상승/유지/하락)
- 계절성 요인 (분기말 처분 수요 등)
- 시세 계수 C3 산출 (0.80 ~ 1.15 범위)

### 5. 견적 산출 엔진 (Calculation Engine)
이력 기준가에 모든 계수를 적용하여 최종 견적가 산출.

상세 공식은 `03-calculation.md` 참조.

**핵심 단계**:
1. 품목별 단위 견적가 산출 (이력 × 계수 5종)
2. 전 품목 합산
3. 처리비용 차감 (물류·파쇄·검수)
4. 목표 마진 차감
5. 리스크 보수 차감
6. 신뢰도 점수 산출

### 6. 최종 견적서 (Quotation Output)
산출된 견적을 영업담당자와 승인자에게 표시.

**출력물**:
- 화면 견적서 (실시간 조회·수정)
- PDF 견적서 (고객 제출용)
- 엑셀 단가표 (내부 검토용)
- 입찰서 변환 (공개입찰 양식)

**승인 워크플로우**:
- 5천만원 이하: 영업담당자 자체 결정
- 5천만원 ~ 1억: 팀장 승인
- 1억 초과: 본부장 승인

## 데이터 소스 (4가지)

| 소스 | 용도 | 갱신 주기 |
|---|---|---|
| 과거 입찰 이력 | 낙찰 가능성 예측, 기관별 패턴 분석 | 입찰 완료 시 |
| 매각 거래 이력 | 이력 기준가 산출 (가장 중요) | 매각 완료 시 |
| 자산 마스터 DB | 모델 정규화 기준, 감가상각 기준 | 신규 모델 등록 시 |
| 외부 시세 | 시세 계수 산출, 트렌드 반영 | 일 1회 자동 크롤링 |

## 단계별 상세 처리

### 입력 단계
- 엑셀 업로드 시: 헤더 자동 인식 (모델/수량/등급/연식 컬럼 매핑)
- 미인식 컬럼은 사용자에게 매핑 확인 요청
- 1회 최대 1,000행 업로드 (이상 분할 권장)

### 정규화 단계
- 매칭률 90% 이상: 자동 확정
- 매칭률 70~90%: 사용자 확인 후 확정
- 매칭률 70% 미만: 미매칭 처리, 수동 매칭 필요

### 이력 매칭 단계
- 정확한 모델 매칭 우선
- 매칭 결과 0건이면 유사 스펙 모델로 확장
- 유사 스펙도 0건이면 카테고리 평균값으로 대체 (신뢰도 감소)

### 보정 단계
- 외부 시세 API 응답 캐시 (1시간)
- API 실패 시 직전 캐시 사용 + 경고 표시
- 환율은 한국은행 기준환율 사용

### 산출 단계
- 모든 계산을 트랜잭션 내에서 실행
- 중간 계산값 모두 DB 저장 (역추적용)
- 동일 입력에 대한 재계산은 동일 결과 보장 (결정론적)

### 출력 단계
- PDF 생성은 비동기 큐 처리 (대량 견적 시)
- 견적 유효기간 기본 14일
- 만료된 견적은 재산출 권장 알림
