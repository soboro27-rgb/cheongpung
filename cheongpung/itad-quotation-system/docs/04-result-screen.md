# 04. 견적서 결과 화면

## 화면 개요

견적 산출 완료 후 영업담당자와 승인자가 확인하는 화면. PDF 출력 전 단계.

**경로**: `/quotations/[id]`
**권한**: 작성자, 승인자, 관리자

## 화면 구조

```
┌─────────────────────────────────────────────────────────┐
│ [헤더]                                                   │
│   [상태배지] [견적번호]                                  │
│   고객사 이름 - IT자산 매각 견적서                       │
│   메타데이터               │ 제안 견적가 (강조)          │
│                            │ 신뢰도                       │
├─────────────────────────────────────────────────────────┤
│ [요약 카드 4개 - 가로 배열]                              │
│   이력 기준가 | 시세 보정 | 처리비용 | 예상 마진          │
├─────────────────────────────────────────────────────────┤
│ [품목별 단가표]                          [엑셀 내보내기] │
│   모델 | 등급 | 수량 | 기준가 | 계수 | 단위가 | 소계    │

│   시세 보정                   │   각 거래 카드            │
```

## 컴포넌트 상세

### 헤더

**상태 배지** (좌상단):
- DRAFT: 회색 "임시저장"
- CALCULATED: 청색 "견적 완료"
- PENDING_APPROVAL: 황색 "승인 대기"
- APPROVED: 녹색 "승인됨"
- REJECTED: 적색 "반려"
- EXPIRED: 회색 "만료"

**견적번호**: `Q-YYYY-MMDD-NNN` 형식 (예: `Q-2026-0512-014`)

**메타데이터**:
```
248대 · 5개 품목 · 산출일 2026.05.12 · 유효기간 2026.05.26까지
```

**제안 견적가** (우측 강조):
- 24px 굵게, 파란색 (`text-primary`)
- 통화 형식: `57,530,000원`

**신뢰도 표시**:
- 점수 + 등급 (예: "신뢰도 82/100 — 높음")
- 아이콘으로 시각화 (✓ ⚠ ✗)

### 요약 카드 (4개)

각 카드는 `Card` 컴포넌트, 4열 그리드.

| 카드 | 표시값 | 색상 |
|---|---|---|
| 이력 기준가 | 67,420,000 | 기본 |
| 시세 보정 | +3.2% | 녹색 (음수면 적색) |
| 처리비용 | -4,200,000 | 적색 |
| 예상 마진 | 12.0% | 기본 |

### 품목별 단가표

**컬럼 구성**:

| 컬럼 | 너비 | 정렬 | 표시 |
|---|---|---|---|
| 모델 | 200px | 좌측 | 텍스트 |
| 등급 | 50px | 가운데 | Badge |
| 수량 | 50px | 우측 | 숫자 |
| 기준가 | 80px | 우측 | 통화 (3,000자리) |
| 계수 | 60px | 우측 | "×0.74" 형식 |
| 단위가 | 80px | 우측 | 통화 |
| 소계 | 100px | 우측 | 통화 (굵게) |

**계수 컬럼 클릭 시**:
적용된 모든 계수 (C1~C5)를 팝오버로 표시.

```
이 단가의 산출 근거:
  기준가 P₀:    385,000
  × 등급 (A):   1.00
  × 연식 (5년): 0.35
  × 시세:       1.03
  × 지역:       1.00
  × 기관:       1.02
  ─────────────────────
  단위가:       142,431
```

**하단 합계 행**:
- 배경색 약간 강조 (`bg-secondary`)
- 총 수량과 품목 합계 표시

**경고 메시지**:
이력 부족 또는 미매칭 자산이 있는 경우:
```
⚠ HPE DL380: 이력 부족으로 보수적 계수 적용 (리스크 -5%p 반영)
```

### 산출 근거 (좌측)

테이블 형식, 항목별 금액 표시. 양수는 기본색, 차감은 적색.

각 행에 마우스 오버 시 툴팁으로 산출 방법 설명.

### 참고 이력 (우측)

3~5건의 유사 거래를 카드 형식으로 표시.

```
[좌측 색상 막대 (관련도)]
국민은행 본점 IT자산
2026.02 · 320대 · 낙찰 71,200,000
```

좌측 막대 색상:
- 녹색: 높은 관련도 (동일 기관 또는 동일 카테고리 + 최근 3개월)
- 파란색: 보통 관련도
- 회색: 낮은 관련도 (참고용)

**하단 자동 비교**:
```
대당 평균: 230,500원 (본 견적 232,000원 → 적정)
```

비교 결과 메시지:
- 본 견적이 평균의 ±5% 이내: "적정"
- ±5~15%: "검토 필요"
- ±15% 초과: "재검토 권장"

### 승인 워크플로우

4단계 가로 진행 표시:
1. 영업담당 작성 (완료)
2. 팀장 검토 (대기/생략 조건)
3. 본부장 승인 (생략 조건)
4. 입찰서 변환 (완료 시)

각 단계는 다음 상태:
- `완료`: 녹색, 담당자 이름 + 시각
- `대기중`: 황색, 다음 행동 필요
- `예정`: 회색, 미래 단계
- `생략`: 회색 (취소선), 조건 미충족 시

**자동 라우팅 규칙**:
- 견적가 5천만원 미만: 영업담당자 자체 결정 (팀장 검토 생략 가능)
- 5천만원 ~ 1억: 팀장 승인 필수
- 1억 초과: 팀장 + 본부장 승인

### 액션 버튼 (하단 우측)

권한과 상태에 따라 표시:

| 버튼 | 표시 조건 | 동작 |
|---|---|---|
| 수정 | 작성자, 상태 DRAFT/CALCULATED | 입력 화면으로 이동 (편집 모드) |
| PDF 미리보기 | 모든 권한 | 새 탭에서 PDF 미리보기 |
| 임시저장 | 작성자, 변경 발생 시 | 현재 상태 저장 |
| 팀장 승인요청 | 작성자, 5천만원 초과 | 상태 변경 + 알림 발송 |
| 승인 | 팀장/본부장, 본인 단계 | 다음 단계로 진행 |
| 반려 | 팀장/본부장 | 상태 REJECTED + 사유 입력 |
| 입찰서 생성 | 작성자, 상태 APPROVED | 공식 입찰서 PDF 생성 |
| 견적 복제 | 모든 권한 | 새 견적의 초안으로 복사 |

## 화면 구현 우선순위

Phase 5에서 다음 순서로 구현:

1. 견적 데이터 로드 + 헤더 표시
2. 요약 카드 4개
3. 품목별 단가표 (계수 팝오버 포함)
4. 산출 근거 테이블
5. 참고 이력 카드
6. 승인 워크플로우 시각화
7. 액션 버튼 (PDF 미리보기는 Phase 6)
8. 권한별 표시 분기

## PDF 출력 (Phase 6)

Puppeteer로 HTML → PDF 변환.

PDF 레이아웃:
- 표지 (코어테일 로고, 견적 정보)
- 품목별 단가표 (다중 페이지 지원)
- 산출 근거 요약
- 약관·유효기간
- 담당자 정보

PDF 전용 스타일:
- A4 세로
- 흑백 친화 색상 (인쇄 고려)
- 페이지 번호 푸터
- 헤더에 회사 로고

## 엑셀 출력

SheetJS로 단가표 엑셀 생성. 시트 구성:
1. 견적 요약 (1시트)
2. 품목별 단가표 (1시트)
3. 산출 근거 상세 (1시트)
4. 참고 이력 (1시트)

각 셀에 계산식 보존 (사용자가 엑셀에서 직접 수정·검토 가능하도록).
