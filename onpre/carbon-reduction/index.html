06산식 & 방법론
// 재사용 (reuse)
순절감 = [ 내재탄소 × 대체율 ] − [ 내재탄소 × 리퍼율 ] − 운송배출

// 재활용 (recycle)
순절감 = [ 재활용 절감 ] − 운송배출

// 운송배출 (공통)
운송배출 = (중량kg ÷ 1000) × 거리km × 운송계수 ÷ 1000
Baseline — 처분하지 않았을 경우 발생했을 배출(신규 제조 또는 1차 자원 생산).
Project — 실제 처분 활동에서 발생한 배출(재제조·수거 운송).
대체율 < 1 — 재사용이 신규 구매를 완전히 대체하지 못함을 보수적으로 반영.
이중계상 방지 — 사용단계 배출은 신·구 동일 가정으로 상쇄 처리(미산입).
추적성 — 향후 시리얼 단위로 매핑하면 기기별 탄소원장 구축 가능.
검증 경로 — 계수 출처 명시 → 제3자 검증 → 등록부 등재 → 자발적 크레딧.
