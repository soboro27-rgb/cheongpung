# Estimate — 자산매각 입찰 단가 산출 도구

금융권 자산매각 입찰에서 과거 투찰 이력을 참조해 신규 견적 단가를 산출하는 로컬 Excel 도구입니다.

---

## 폴더 구조

```
edtimate/
├── estimate.py              ← 메인 스크립트
├── data/
│   ├── 과거입찰데이터.xlsx   ← 과거 입찰 이력 입력 파일
│   └── 신규자산리스트.xlsx   ← 고객사 자산 목록 입력 파일
└── output/
    └── 견적서_YYYYMMDD_HHMM.xlsx   ← 생성된 견적서 (자동 저장)
```

---

## 사용 순서

### 1단계: 과거 입찰 데이터 입력
`data/과거입찰데이터.xlsx` 열기 → **입찰이력** 시트에 입력

| 컬럼 | 설명 |
|------|------|
| 입찰일 | 예: 2025-12-01 |
| 고객사명 | 발주처 |
| 카테고리 | PC / 노트북 / 서버 / 프린터 / 복합기 / 태블릿 / 모바일 / 기타전산기기 |
| 모델명 | 장비 모델명 |
| 제조사 | Dell / HP / Lenovo 등 |
| 제조연도 | 4자리 연도 |
| 수량 | 대수 |
| 상태 | 상 / 중 / 하 |
| 투찰단가(원) | 대당 투찰 금액 |
| 낙찰여부 | **낙찰** 또는 **유찰** |
| 비고 | 특이사항 |

> 12월 유찰 데이터, 기타 참고 이력 모두 입력하세요. 많을수록 정확합니다.

---

### 2단계: 신규 자산 리스트 입력
고객사에서 보내온 자산 목록을 `data/신규자산리스트.xlsx` 의 **자산목록** 시트에 입력
(또는 고객사 엑셀을 열어 열 이름을 맞춰서 붙여넣기)

---

### 3단계: 견적서 생성

```bash
python estimate.py
```

`output/견적서_날짜시간.xlsx` 파일이 생성됩니다.

---

## 생성된 견적서 구성

### 시트 1 — **견적입력** (작업 시트)

| 컬럼 색상 | 의미 |
|-----------|------|
| 파란색 (H~M) | 과거 이력 기반 자동 계산값 (최저/최고/평균/낙찰평균/유찰평균) |
| **노란색 (N열)** | ★ **직접 입력** — 여기에 투찰 단가 입력 |
| 노란색 (O열) | 소계 자동 계산 (수량 × 투찰단가) |

**H~M 컬럼 참고 방법:**
- `낙찰평균` 이상으로 단가를 써야 낙찰 가능성 높음
- `유찰평균` 이하면 과거에 이미 탈락했던 수준

### 시트 2 — **과거데이터참조**
- 전체 입찰 이력 (녹색=낙찰, 주황=유찰)
- 하단에 카테고리·상태별 단가 요약표 자동 생성

### 시트 3 — **최종견적서**
- 견적입력 N열의 단가를 자동 참조하여 완성
- 별도 입력 없이 자동으로 완성됨
- 인쇄 후 제출 가능

---

## 파일 직접 지정 실행

```bash
# 고객사 파일명이 다를 경우
python estimate.py 고객사자산목록.xlsx 과거입찰데이터.xlsx

# 신규 자산 파일만 지정 (과거 데이터는 data/ 폴더 기본값 사용)
python estimate.py 고객사자산목록.xlsx
```
