# 매출처 마케팅 대시보드 프로젝트

## 프로젝트 목표
25년/26년 주문 데이터를 분석해서 미비 매출처를 발굴하고,
재활성화·크로스셀·업셀 마케팅 정책을 수립할 수 있는 HTML 대시보드를 만든다.

## 입력 데이터
- 파일: 25년 주문내역 엑셀, 26년 주문내역 엑셀 (각각 1개씩, 총 2개)
- 컬럼 (총 45개):
  주문상태, 주문묶음번호, 판매사이트, 품목코드, 품명, 규격, 상품명,
  수량, 단가, 판매가, 부가세, 합계금액, 수수료, 수수료율(%), 정산금액,
  재고원가, 할인가, 마진, 세액포함 여부, 영업담당, 주문일자,
  쇼핑몰 주문번호, 수령자명, 수령자전화번호, 수령자핸드폰, 우편번호,
  주소1, 주소2, 대분류, 중분류, 소분류, 배송방법, 운송장번호1, 운송장번호2,
  수주상태, 작지상태, 작업지시번호, 작업지시량, 실적수량, 검사수량,
  출고수량, 반품수량

## 거래처 식별 기준
- 1차: 수령자명 + 수령자전화번호 조합으로 동일 거래처 판별
- 2차: 표기 흔들림 정리 (예: "A전자", "(주)A전자", "에이전자" → 통일)

## 분석 세그먼트 (4개 그룹)
1. **충성**: 25년·26년 모두 거래
2. **이탈(재활성화 대상)**: 25년 거래 있음, 26년 거래 없음 — 최우선
3. **크로스셀 대상**: 특정 대분류/중분류만 구매한 거래처
4. **업셀 대상**: 주문빈도는 평균 이상, 평균 객단가는 전체 평균 -30% 이하

## 대시보드 구성 (HTML 1개 파일)
1. KPI 카드 4개 (전체 거래처 수, 재활성화 47, 크로스셀 68, 업셀 52)
2. 거래처 세그먼트 분포 막대바
3. 재활성화 우선순위 TOP 리스트 (25년 매출 큰 순, 클릭하면 상세)
4. 크로스셀 매트릭스 (어떤 카테고리만 사는 거래처 → 추천 카테고리)
5. 업셀 후보 리스트 (객단가 비교)
6. 영업담당자별 거래처 현황
7. 지역(우편번호 앞 3자리) 히트맵
8. 월별 매출 추이 (25 vs 26 라인 차트)

## 출력
- 단일 HTML 파일 (sales_dashboard.html)
- 더블클릭으로 브라우저에서 바로 열리도록
- 외부 라이브러리는 CDN으로 (chart.js 등)
- 데이터는 HTML 안에 임베드 (별도 파일 없이 단독 실행)

## 기술 스택
- Python (pandas, openpyxl) — 데이터 처리
- HTML + JavaScript (Chart.js) — 대시보드 렌더링
- 실행 방식: python build_dashboard.py 한 줄로 끝

## 디자인 원칙
- 한국어 UI
- 깔끔한 플랫 디자인 (그라데이션, 그림자 X)
- 비개발자 영업팀이 바로 이해할 수 있는 단순한 화면

## 작업 순서
1. 두 엑셀 파일 읽어서 통합
2. 거래처 식별 및 표기 정리
3. 4개 세그먼트 자동 분류
4. 각 세그먼트별 우선순위 점수 계산
5. HTML 대시보드 생성
6. 영업 액션 리스트 추출 (어느 거래처에 무엇을 제안할지)
