# 서버파츠비더 — 서버부품 즉시판매 · 비딩 플랫폼

월드메모리 자사 재고(즉시판매)와 퀵솔 등 외부 소싱 비딩을 한 곳에서 고객에게 보여주고,
관심품목이 맞는 고객에게 카카오 알림톡으로 알리는 사이트입니다.

## 상품 두 종류

| | 즉시판매 | 비딩 |
|---|---|---|
| 출처 | 자사 재고 | 퀵솔 등 외부 소싱 |
| 등록 | `seversales\자동화\script\product_data.csv`가 바뀌면 1분 안에 자동 반영 | 관리 > 비딩 엑셀 등록 (퀵솔 원본 그대로 가능) / 1건 등록 |
| 가격 | 재고원본의 별도가 (VAT 별도) | 고객이 개당 희망가 제출 (최대 3회, 올리기만) |
| 고객 행동 | 구매요청 → 관리자 확정 | 입찰 → 마감 → 파트너 결과 입력 → 낙찰/미성사 |
| 고객에게 안 보이는 것 | 재고원본 '메모' 열 | 소싱처, 품번, 환율·마진 계산 |

## 비딩 흐름

1. 퀵솔 엑셀 업로드 → 미리보기 → 등록 (오픈 시각·진행 시간·선공개 시간 지정, 기본 48시간·3시간)
2. **선공개**: 오픈 후 3시간은 거래이력 있는 고객에게만 보이고 알림톡 발송
3. 선공개가 끝나면 나머지 승인 고객에게 공개 + 알림톡
4. 마감 3시간 전 '마감 임박' 알림톡
5. 마감 → '결과 대기'. 관리 > 비딩 상세에서 환율·마진·부대비용 넣으면 파트너 응찰 단가(USD) 계산
6. 파트너 결과 입력: 낙찰 → 고객 낙찰 확정 / 유찰 → '미성사' 안내. 참여 고객 전원에게 알림톡

우리 마감은 파트너 마감보다 앞으로 잡으세요. 마감 연장·단축·취소는 비딩 상세 > 수정.

## 비딩 업체 계정 (퀵솔 등)

- 관리 > **업체** 에서 계정 생성 (업체명 + 영문 아이디). 비밀번호는 자동 생성되어 **한 번만** 보이니 업체에 전달. 분실 시 '비밀번호 재발급'
- 업체는 `/partner` 화면에서 평소 재고리스트 엑셀(Brand · Part Number · Description · QTY · Sell Price)을 그대로 올림 → **검토 대기**
- 관리 > 비딩 상세에서 품목명·분류를 고객용으로 다듬고 **공개하기** → 그때 마진 반영 시작가가 정해지고 관심 고객 알림
- 업체가 보는 것: 자기 품목의 진행 상태, 마감 후 우리 응찰 단가(USD), 결과. 못 보는 것: 고객명, 고객 입찰가, 시작가, 마진
- 관리자가 엑셀로 대신 올릴 때도 '업체 계정'을 고르면 그 업체 화면에 같이 보임

## 시작가 (마진 반영)

- 고객 시작가 = (업체 공급가 × 환율 + 개당 부대비용) × (1 + 마진%), 1,000원 단위 올림
- 기본값(마진·환율·부대비용)은 관리 대시보드에서 설정. 등록·공개할 때 건별로 바꿀 수 있고 마지막에 쓴 값이 다음 기본값
- 고객은 시작가 이상으로만 입찰 가능. 공급가가 BID/CALL이면 시작가 없이 자유 입찰
- 시작가를 직접 정하고 싶으면 '시작가 직접 입력' 칸 사용

## 고객

- 가입 신청(사업자 고객) → 관리 > 고객 에서 **승인** → 승인 알림톡
- **거래이력**: 구매요청 확정이나 비딩 낙찰이 생기면 자동으로 켜짐. 고객 화면에서 직접 켜고 끌 수도 있음
- **기존 고객 일괄 등록**: 관리 > 고객 > 기존 고객 엑셀 등록 (회사명·담당자·휴대폰…). 바로 승인 + 거래이력 있음 + 관심품목 '전체', 초대 알림톡에 임시 비밀번호(6자리)
- 고객 아이디 = 휴대폰 번호. 비밀번호 분실 시 지금은 관리자가 재등록해야 함 (보완 예정)

## 카카오 알림톡

알림톡은 사전 준비가 끝나야 실제로 나갑니다. 그 전까지는 관리 > 알림톡 에 **설정 필요**로 쌓이고, 준비가 끝나면 **미발송 건 다시 보내기**로 보낼 수 있습니다.
준비 절차와 등록할 문구: [알림톡_템플릿.md](알림톡_템플릿.md)
