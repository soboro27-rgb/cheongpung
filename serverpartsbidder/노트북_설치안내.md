# 서버파츠비더 — 노트북으로 옮겨 쓰기

## 들어 있는 것

| 폴더/파일 | 내용 |
|---|---|
| `app\` | 프로그램 (FastAPI) |
| `data\spb.db` | 회사 PC에서 묶은 시점의 DB (관리자·퀵솔·우리시스템 계정, 재고, 비딩, 설정) |
| `data\alimtalk.json` | 알림톡 설정 틀 (키는 비어 있음) |
| `stock\product_data.csv` | 묶은 시점의 자사 재고 사본 |
| `서버실행.bat` | 실행 |
| `사용설명.md`, `알림톡_템플릿.md`, `외부접속_포트개방.md` | 사용법 |
| `.gitignore` | 푸시할 때 `data\`, `stock\`, 키 파일이 올라가지 않게 막음 |

## 노트북에서 실행

1. 압축을 원하는 곳에 풉니다 (예: `D:\serverpartsbidder`).
2. **Python 3.10 이상**이 필요합니다. 없으면 python.org에서 설치하고, 설치 첫 화면에서 "Add python.exe to PATH"를 체크하세요.
3. `서버실행.bat` 더블클릭 → 처음엔 패키지 설치로 1~2분 걸립니다.
4. 브라우저에서 http://localhost:8060 , 관리 화면은 `/admin`.

같은 폴더의 `data\`를 쓰므로 계정과 데이터가 그대로 이어집니다. 세션키는 새로 만들어져서 처음 한 번 다시 로그인하면 됩니다.

## 알아 둘 점

- **재고는 묶은 시점 사본입니다.** 노트북에선 회사 재고원본이 자동 갱신되지 않습니다. 새 재고를 반영하려면 최신 `product_data.csv`를 `stock\`에 덮어쓰면 1분 안에 반영됩니다.
- **회사 PC 서버와 따로 돕니다.** 노트북에서 입력한 내용은 회사 PC DB에 반영되지 않고, 그 반대도 마찬가지입니다. 한쪽만 쓰세요.
- **푸시(GitHub 등)**: `.gitignore`가 DB·키·재고를 빼 줍니다. 저장소는 비공개로 만드세요.
- **클라우드 배포 시**: 서버의 데이터 폴더가 재시작 후에도 남는 디스크여야 합니다. 환경변수 `SPB_DATA`에 그 경로를 지정하고, 첫 배포 때 `data\spb.db`를 그 경로에 올리면 지금 데이터로 시작합니다. 재고 사본 위치는 `SPB_STOCK_CSV`로 지정할 수 있습니다.
- **외부에 공개하기 전**: 관리자 비밀번호(`soboro27` / `11111111`)를 꼭 바꾸고, HTTPS를 붙이세요.
