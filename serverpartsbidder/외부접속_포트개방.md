# 사외 고객 접속 — 공유기 포트 개방

서버파츠비더는 이 PC(사내 상시서버)에서 8060 포트로 돌고 있습니다. 사내에서는 바로 접속되고, 사외 고객이 들어오려면 공유기에서 포트를 열어야 합니다.

## 지금 상태 (2026-11-06 확인)

| 항목 | 값 |
|---|---|
| 이 PC 내부 IP | 192.168.1.206 (기존 메모상 1.210이었는데 바뀌어 있음 → 고정 필요) |
| 공유기(게이트웨이) | 192.168.1.1 |
| 윈도우 방화벽 | python.exe 허용 규칙 있음 → 추가 작업 없음 |
| 앱 포트 | 8060 |

## 할 일 (공유기 관리자 비밀번호가 있는 분)

1. **이 PC 내부 IP 고정**: 공유기 관리 > DHCP 고정 할당에서 이 PC를 지금 주소(192.168.1.206)로 고정합니다. 고정하지 않으면 재부팅 후 IP가 바뀌어 외부 접속이 끊길 수 있습니다.
2. **포트포워딩 추가**: 외부 포트 `8060` → 내부 IP `192.168.1.206`, 내부 포트 `8060`, TCP
3. **공인 IP 확인**: 공유기 관리 첫 화면의 외부 IP. 회사 인터넷이 유동 IP면 DDNS(ipTIME이면 `xxx.iptime.org`)를 켜 두면 주소가 안 바뀝니다.
4. **알림톡 주소 반영**: `%LOCALAPPDATA%\serverpartsbidder\alimtalk.json` 의 `site_url` 을 `http://공인IP또는DDNS:8060` 으로.
5. **확인**: 휴대폰 LTE(와이파이 끄고)로 그 주소 접속.

## 알아 둘 점

- 이 PC가 꺼지거나 재부팅 중이면 고객도 접속 못 합니다. 로그인 시 자동 실행은 `서버실행.bat` 바로가기를 시작프로그램(`shell:startup`)에 넣으면 됩니다. 단, 윈도우 로그인 전에는 안 뜹니다.
- 지금은 **http**(암호화 없음)입니다. 고객 비밀번호가 오가므로 정식 오픈 전에 HTTPS를 붙이는 것을 권합니다. DDNS 주소가 정해지면 인증서 적용 방법을 같이 잡겠습니다.
- 관리 화면(`/admin`)도 같은 주소로 열립니다. 관리자 비밀번호를 첫 비밀번호(11111111)에서 꼭 바꿔 주세요.
