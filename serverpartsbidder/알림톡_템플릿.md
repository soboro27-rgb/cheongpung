# 카카오 알림톡 준비 절차

서버파츠비더는 **솔라피(SOLAPI)**를 통해 알림톡을 보냅니다. 아래 준비가 끝나기 전까지 알림은 발송되지 않고 관리 > 알림톡에 '설정 필요'로 쌓입니다.

## 1. 준비 순서 (회사 명의)

| # | 할 일 | 어디서 | 비고 |
|---|---|---|---|
| 1 | 카카오톡 채널 개설 (예: "서버파츠비더" 또는 "월드메모리") | 카카오톡 채널 관리자센터 | 사업자등록증으로 **비즈니스 채널 인증** |
| 2 | 솔라피 가입 + 사업자 인증 | solapi.com | 회사 계정으로 |
| 3 | 발신번호 등록 | 솔라피 콘솔 | 알림톡 실패 시 대체문자용, 회사 대표번호 |
| 4 | 카카오 채널 연동 → **발신프로필 ID(pfId)** 받기 | 솔라피 콘솔 > 카카오 채널 | |
| 5 | 아래 7개 템플릿 등록 → 검수 → **템플릿 ID** 받기 | 솔라피 콘솔 > 알림톡 템플릿 | 검수 보통 영업일 1~3일 |
| 6 | **API Key / API Secret** 발급 | 솔라피 콘솔 > API Key | |
| 7 | 잔액 충전 | 솔라피 | 건당 요금은 솔라피 요금표 확인 |

## 2. 설정 파일에 입력

서버PC에서 `%LOCALAPPDATA%\serverpartsbidder\alimtalk.json` 을 메모장으로 열어 채웁니다. 저장하면 바로 적용됩니다.

```json
{
  "provider": "solapi",
  "api_key": "NCS...",
  "api_secret": "...",
  "sender_phone": "0212345678",
  "pf_id": "KA01PF...",
  "site_url": "http://공인IP:8060",
  "templates": {
    "signup_approved": "KA01TP...",
    "invite": "KA01TP...",
    "new_stock": "KA01TP...",
    "bid_open": "KA01TP...",
    "bid_closing": "KA01TP...",
    "bid_result": "KA01TP...",
    "order_received": "KA01TP..."
  }
}
```

`site_url` 은 알림톡 안의 '바로가기' 주소입니다. 포트 개방 후 고객이 실제로 열 수 있는 주소를 넣으세요.

## 3. 등록할 템플릿 문구

**글자 하나까지 똑같이** 등록해야 발송됩니다. `#{…}` 는 변수로 그대로 둡니다. 문구를 바꾸려면 `app/notify.py`의 TEMPLATES도 같이 바꿔야 합니다.

### signup_approved — 가입 승인
```
[서버파츠비더] #{이름}님, 가입이 승인되었습니다.
관심품목을 등록하시면 입고·비딩 소식을 알림톡으로 보내드립니다.

바로가기: #{링크}
```

### invite — 기존 고객 초대
```
[서버파츠비더] #{이름}님, 월드메모리 서버부품 거래 사이트에 초대합니다.
아이디: #{아이디}
임시 비밀번호: #{비밀번호}
로그인 후 비밀번호를 바꿔 주세요.

바로가기: #{링크}
```

### new_stock — 관심품목 입고
```
[서버파츠비더] #{이름}님 관심품목이 입고되었습니다.
품목: #{품목}
수량: #{수량}개
가격: #{가격}

바로가기: #{링크}
```

### bid_open — 비딩 오픈
```
[서버파츠비더] #{이름}님, 관심품목 비딩이 열렸습니다.
품목: #{품목}
수량: #{수량}개
마감: #{마감}

바로가기: #{링크}
```

### bid_closing — 마감 임박
```
[서버파츠비더] #{이름}님, 비딩 마감이 다가왔습니다.
품목: #{품목}
마감: #{마감}

바로가기: #{링크}
```

### bid_result — 비딩 결과
```
[서버파츠비더] #{이름}님, 참여하신 비딩 결과를 알려드립니다.
품목: #{품목}
결과: #{결과}

바로가기: #{링크}
```

### order_received — 구매요청 접수
```
[서버파츠비더] #{이름}님, 구매요청이 접수되었습니다.
품목: #{품목}
수량: #{수량}개
담당자가 확인 후 연락드립니다.
```

## 4. 검수 주의

- 알림톡은 **정보성** 메시지만 됩니다. '관심품목 입고', '비딩 오픈'은 고객이 직접 관심품목을 등록하고 수신 동의한 경우의 안내라는 점을 템플릿 설명에 적어 주세요. 광고성으로 판단돼 반려되면 해당 2종은 친구톡이나 문자로 돌리는 방안을 검토합니다.
- 템플릿에 '바로가기' 링크 대신 **웹링크 버튼**을 달라고 요구받을 수 있습니다. 그때는 버튼을 추가하고 알려 주세요. 코드를 맞춰 드립니다.
- 임시 비밀번호가 들어간 '초대' 템플릿이 반려되면, 비밀번호 없이 "휴대폰 번호로 로그인 후 비밀번호를 설정"하는 방식으로 바꿉니다.
