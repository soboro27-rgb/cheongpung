## 2026-08-24

**요청**: WS300P가 국내 최초로 입고되어 고객사 납품 완료. `ws300P/update/`에 실제 MSI 공식 매뉴얼(Quick Start Guide, User Guide) 추가해두었으니 내용 반영해서 가격(약 1억9천8백만원)과 페이지 업데이트 후 푸시·배포 요청.

**작업 내용**:
- 첨부된 공식 매뉴얼(System Specifications, Rear/Top I/O 페이지) 대조 결과, 기존 페이지 스펙 중 실제와 다른 부분 다수 발견 → 정정
  - 네트워크: 40GbE×2 + 100GbE×1 + 1GbE×1 (오류) → **400G QSFP112×2(ConnectX-8) + 10GBase-T×1 + 1000Base-T×1(BMC 전용 관리)**
  - 메모리 대역폭: CPU 480GB/546GB/s, GPU 192GB/8TB/s (오류, 합계도 748GB와 불일치) → **CPU 496GB LPDDR5X/396GB/s, GPU 252GB HBM3e/7.1TB/s** (합계 748GB로 정합)
  - 치수: 약 250×500×550mm (출처 불명) → **527.9×247.8×567.7mm** (공식 스펙)
  - 상단/후면 I/O 포트 구성 전체 정정, 스토리지(M.2 4슬롯, 2TB NVMe×2 RAID1)·보안(TPM2.0)·BMC(ASPEED AST2600) 스펙 신규 추가
- 국내 도입가 ₩180,000,000 → **₩198,000,000**으로 업데이트, 연동된 CAPEX/OPEX/3년 TCO·절감률 수치 전체 재계산 (3년 TCO ₩211,040,000→₩229,040,000, 절감액 ~4.8억→~4.6억 등)
- 히어로 섹션에 "🇰🇷 국내 최초 입고 · 고객사 납품 완료" 배지 추가
- `cheongpung/ws300P/index.html` 커밋·푸시 → GitHub Pages 자동 배포 확인 완료
