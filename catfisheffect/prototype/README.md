# 캣피쉬 파일럿 — 클로바미니 프로토타입

클로바미니는 블루투스 아웃풋(A2DP) 전용이라 마이크를 넘겨받을 수 없습니다. 그래서
역할을 나눕니다.

| 역할 | 담당 |
|---|---|
| 마이크 입력 | 노트북 마이크 (`sounddevice`) |
| STT | faster-whisper (로컬, API 키 불필요) |
| 판단 (캣피쉬 코어 프롬프트) | Claude API (`claude-opus-4-8`) |
| TTS | edge-tts (온라인, 무료, 한국어 자연스러움) |
| 음성 출력 | 클로바미니 (블루투스로 페어링, Windows 기본 출력 장치) |

지금 구현된 로직은 브랜드 원칙 그대로입니다 — 판단하지 않음, 트리거 기반 개입,
질문 우선. 트리거에 해당하지 않으면 캣피쉬는 `PASS`를 반환하고 아무 말도 하지
않습니다. 프롬프트 원문은 `catfish_core_prompt.md`에 있고, 코드 수정 없이 이
파일만 고쳐서 프롬프트를 튜닝할 수 있습니다.

## 사전 준비

1. **Anthropic API 키 발급** — [console.anthropic.com](https://console.anthropic.com)
   에서 발급. (지금 쓰고 계신 Claude Code 구독과는 별개의 자격 증명입니다.)
   ```
   setx ANTHROPIC_API_KEY "여기에_발급받은_키"
   ```
   (설정 후 터미널을 새로 열어야 반영됩니다.)

2. **파이썬 패키지 설치**
   ```
   pip install -r requirements.txt
   ```
   `faster-whisper`가 `av` 패키지를 함께 설치하므로 별도 ffmpeg 설치는
   필요 없습니다.

3. **클로바미니 블루투스 페어링** — 기기 뒷면 블루투스 버튼을 3초간 눌러
   페어링 모드로 진입 → 노트북 블루투스 설정에서 연결.

4. **클로바미니를 Windows 기본 출력 장치로 설정** — 설정 → 시스템 → 사운드
   → 출력에서 클로바미니 선택. (스크립트는 시스템 기본 출력 장치로 재생하므로
   이 설정이 안 되어 있으면 노트북 스피커로 소리가 나갑니다.)

## 실행

```
python catfish_pilot.py
```

- Enter를 누르면 녹음 시작, 다시 Enter를 누르면 녹음 종료.
- 녹음 구간마다 캣피쉬는 두 가지를 함께 합니다:
  1. **관찰자** — 사실관계/결정/액션아이템을 판단 없이 한 줄로 정리 (음성 재생 없음, 콘솔에 "[요약 기록]"으로만 표시되고 누적됨)
  2. **화자** — 트리거 조건에 해당할 때만 짧게 개입, 클로바미니로 발화
- Ctrl+C로 종료하면 그동안 누적된 요약이 `meeting_notes_YYYYMMDD_HHMMSS.md` 파일로
  이 폴더에 저장됩니다.

## 참고

- STT 모델(faster-whisper `small`)은 최초 실행 시 자동 다운로드됩니다
  (인터넷 필요, 약 500MB).
- edge-tts는 온라인 서비스라 인터넷 연결이 필요합니다.
- 지금은 Enter 키로 녹음을 시작/종료하는 방식입니다(실제 하드웨어의 원터치
  버튼을 흉내). 상시 듣고 있다가 자동으로 트리거를 감지하는 방식은 다음
  단계입니다.
- 프롬프트를 수정하고 싶으면 `catfish_core_prompt.md`만 고치면 됩니다 —
  코드 변경 불필요.
