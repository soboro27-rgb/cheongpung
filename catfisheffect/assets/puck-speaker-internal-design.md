# 캐피시AI 보이스 스피커 — 내부 전자 설계 (개념 블록 다이어그램 v0.1)

시각 자료: `puck_speaker_internal_block_diagram.svg`

## 1. 설계 전제

- Ø58 × H32mm, ~85g 퍽 하우징 안에 아래 부품을 조립해 넣는다는 가정.
- 퍽 하드웨어는 **음성 입출력 + BT HFP/BLE 통신까지만** 담당한다. 실제 LLM
  API 호출은 페어링된 고객사 PC/노트북의 컴패니언 클라이언트에서 수행되며,
  이 구간은 하드웨어 범위 밖이다. 이 구성은 "당사는 회의 콘텐츠에 접근하지
  않는다"는 사이트 카피와 일치한다 — 기기가 클라우드에 직접 연결되지 않고,
  고객이 소유한 PC를 통해서만 고객의 LLM 계정에 도달한다.
- USB-C는 전원 전용 (데이터 핀 미사용) — 인증서/펌웨어 노출 표면 최소화.
- 오디오는 RAM에서만 일시 버퍼링되며 로컬 플래시에 영구 저장하지 않는다
  (보안 페이지의 "회의 콘텐츠 미접근" 원칙과 일치).

## 2. 부품 인덱스 (참조 부호)

| Ref | 구성요소 | 역할 |
|---|---|---|
| U1 | BT/BLE 오디오 SoC | 페어링·스트리밍·상태 제어 허브 |
| U2 | 원거리 음성 전처리 프로세서 | 빔포밍·AEC·노이즈 억제 |
| MIC1–6 | PDM MEMS 마이크 ×6 | 360도 원형 어레이 픽업 |
| SPK1 | 모노 마이크로스피커 | 상태음·음성 피드백 |
| LED1–3 | 상태 표시 라이트파이프 링 | 대기/듣는중/응답중 시각화 |
| SW1 | 원터치 호출 버튼 | 회의 호출 트리거·웨이크업 |
| U3 | PMIC / 충전 IC | 배터리 충전·전원 분배 |
| BT1 | Li-Po 배터리 팩 (~320mAh) | 무선 구동 전원 |
| J1 | USB-C 리셉터클 (전원 전용) | 충전 입력 |
| ANT1 | BT 안테나 | 무선 링크 |

## 4. 전력 예산 (추정치, 미실측)

- 활성 청취/스트리밍 전류: 약 90–120mA
- 대기(딥슬립) 전류: 1mA 미만
- 배터리 용량: ~320mAh
- 예상 연속 사용: 약 2.5–3.5시간
- 예상 대기 지속: 약 2–3주 (일 1회·1시간 회의 가정)

## 5. 남은 검증 과제

- 실제 부품 선정, PCB 배치, RF 인증(KC 등), 음향 튜닝, 열설계는 하드웨어
  엔지니어링 팀 또는 EMS 파트너 검증 필요.
- 전력 수치는 실측 프로파일링 필요.
- ANT1 배치는 하우징 상단 비금속 영역과 조율 필요.
