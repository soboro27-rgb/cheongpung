# 부품 소싱 경로 메모

`puck-speaker-internal-design.md`의 BOM을 기준으로, 실제 어디서/어떻게 구매하는지
정리. (2026-07-13 논의 기준, 확정 소싱처 아님)

## 1. 범용 부품/모듈 — 바로 소량 구매 가능

MIC1–6(MEMS 마이크), BT1(배터리), J1(USB-C 커넥터), U3(PMIC/충전 IC),
LED1–3, SW1(터치버튼) 등.

- 해외: DigiKey, Mouser, LCSC(중국산, 저렴)
- 국내: 디바이스마트, 엘레파츠, 아이씨뱅큐(icbanq) — 소량/시제품 단위 국내 배송

## 2. 특수 칩 (U1 BT/BLE SoC, U2 원거리 음성 프로세서)

Qualcomm QCC304x급, XMOS XVF3800급 같은 칩은 개인/스타트업이 낱개로 바로
설계에 쓰기 어려운 경우가 많음(설계 지원, MOQ, NRE 문제).

- 현실적 방법: 이미 해당 칩을 얹은 **BT 오디오 모듈**을 구매 (예: 알리바바에서
  "QCC3040 module", "far-field mic array BT audio module" 검색)
- 프로토타입 단계에선 칩 단위 설계보다 모듈 조합이 훨씬 빠름

## 3. 시제품/양산 — EMS·ODM 파트너 경로 (권장)

블록 다이어그램 + BOM을 그대로 들고 EMS/ODM 업체에 제작 의뢰하는 것이 일반적.

- 국내: 구로/가산디지털단지, 시흥 인근 EMS 업체
- 해외: 심천(선전) 화창베이 계열 하드웨어 ODM — BT 오디오/스마트스피커류
  제작 경험 많은 업체 다수

## 4. 인증 관련

국내 판매 시 무선기기라 **KC 인증(전파인증)** 필수. 부품/모듈 소싱 단계부터
인증 가능 여부를 EMS 파트너와 함께 확인 필요.
